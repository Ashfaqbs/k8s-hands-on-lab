- create the code yaml  apply the file
kubectl apply -f springboot-single.yaml
- create custom cacerts 
openssl req -x509 -newkey rsa:2048 -keyout key.pem -out cert.pem -days 365 -nodes -subj "/CN=springboot.local"

- Add in secrets via command cli , or manifest file (take the content and use base64 and paste the content )
cat cert.pem | base64 | tr -d '\n' -> gives the content 
cat key.pem | base64 | tr -d '\n'


apply the secret file  
kubectl apply -f springboot-https-ingress.yaml

create the ingress mention the host, tls provide the secret name etc..
update the host and minikube ip in /etc/host and 


test the url
