when the use case or the task is done, we usually for cleanup
remove resources like deployment, service but in this case where we have a DB which use a 
volume ie PVC we have to remove PVC objects as well, else the data will be there until removed in db
and if the PVC is accidenlty or used the same PVC if the PVC was  not removed we can see the old data in DB and finally in app.


Remove all the objects post usage.
